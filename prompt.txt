Imagine that you are a systems researcher studying collaborative large language model inference on heterogeneous edge devices. Consider a system in which a laptop and a smartphone jointly execute a transformer model. The laptop has a powerful CPU and GPU, while the smartphone has less memory, lower sustained performance, and stricter thermal limits. The goal is to improve inference throughput by using resources from both devices without introducing excessive communication or memory overhead. The model can be partitioned in two main ways. Layer-level partitioning assigns complete transformer layers to different devices, while tensor-level partitioning divides individual matrix operations between the laptop and smartphone. The devices communicate over a local network, so transferring intermediate tensors introduces additional latency. Some communication may overlap with computation, but synchronization dependencies prevent all communication costs from being hidden. The system therefore uses a runtime scheduler that estimates computation time, communication time, available memory, and synchronization overhead before selecting a partitioning strategy. The scheduler must also account for temporary buffers, backend workspaces, cached tensors, and duplicated intermediate data because actual peak memory usage can be higher than the theoretical tensor size. Prefill and decoding should be treated differently. During prefill, many tokens are processed together and large matrix multiplications provide substantial parallelism. During decoding, only a small number of tokens are processed at each step, so communication and synchronization overhead may become more important. Design an adaptive scheduling strategy for this system. Explain how it should choose between layer-level and tensor-level partitioning, estimate communication and computation costs, prevent memory overflow, and adapt its decisions between prefill and decoding. Also describe an experimental methodology comparing smartphone-only execution, laptop-only execution, static layer partitioning, static tensor partitioning, and adaptive hybrid scheduling. Discuss which measurements would demonstrate a real performance improvement.
