# 32B ShareGPT50 Planner 消融：w/o Adaptive Chunk（Fixed-64）

- 模型：Qwen3-32B-Q4_K_M
- 数据集：ShareGPT50_short，0 / 128 / 256 / 512 / 1024 五组，共 50 条、27,417 tokens；运行 50/50 PASS
- 消融：禁用请求期动态 Chunk 搜索，选定 `XC=XG=XP=64`；保留运行时 tiny-tail 合并
- Placement：`G7,P4,G7,P4,G8,P5,G7,P4,G7,P4,G7`（与 Full Cycle 相同）
- 保留：常驻 llama-server、GPU 双 Bank、后台异步预取、Drain-First、Phone HTP、多轮执行
- Full Cycle 参考基线：`32b-server-chunk256-all50-new/summary.csv`（仓库既有 50 条实验汇总）
- Fixed-64 运行指纹：`127bf5a70ce5`
- 统计：50 条对照表使用相同的完整输入集合；逐请求平均表按标明的样本数汇总。加权吞吐 = 总 tokens × 1000 / 总 Prefill 时间 (ms)
