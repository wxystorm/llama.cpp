# 32B ShareGPT50 Runtime 消融：w/o Async Prefetch（同步按需权重加载）

- 模型：Qwen3-32B-Q4_K_M
- 数据：ShareGPT50，0 / 128 / 256 / 512 / 1024 五组，各 10 条，共 50 条、27,417 tokens
- 对比：Full Cycle（后台异步 GPU Bank Refill）vs. w/o Async Prefetch（GPU Worker 同步按需 Refill）
- 分层：`G7,P4,G7,P4,G8,P5,G7,P4,G7,P4,G7`
- 控制变量：保留双 GPU Bank、初始两个 GPU Region 权重驻留、Drain-First、多轮跨端执行；同一模型、Prompt、Profile、固定分层与逐 Prompt XC/XG/XP（重放 Full Cycle `requests.jsonl`）
- 消融机制：关闭 GPU Bank Mover 后台线程；等待上一同 Bank Region 排空，下一 GPU Region 首个 Chunk 就绪时同步加载权重。每条请求 4 次同步 Refill
- Full Cycle 基线：`32b-server-chunk256-all50-new/summary.csv`
- 消融结果目录：`32b-ablation-wo-async-prefetch-all50/`
- 记录来源：前 49 条 Prompt 的 `llama-server` 控制台 Prefill 耗时；最后一条 `prompt_1024_09.txt` 为 1,747 tokens、127.452 tok/s，耗时由 tokens / tok/s 反推约 13,707.121 ms，汇总值因此带有微小舍入误差

## 1. 加权 Prefill 吞吐与相对提速

加权吞吐 = 总 tokens × 1000 / 总 Prefill 时间（ms）；相对下降 = 1 − 消融吞吐 / Full Cycle 吞吐；Full Cycle 提速 = Full Cycle 吞吐 / 消融吞吐。

| 0 | 10 | 911 | 50.245 | 34.191 | 31.95% | 1.470× |
