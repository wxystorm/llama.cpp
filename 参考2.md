对。按你现在这版源码，最合适的做法就是把 **`ffn_norm` 的 `SET_TENSOR` 暂存下来**，等紧接着的 `ggml_backend_rpc_graph_compute()` 到来时，把：

```text

+
GRAPH_RECOMPUTE_SNAPSHOT
```

组成一个新的 RPC 一起发。

你现在 PC→Phone 的 `ffn_norm` 正是在 `active_count == 1` 里走 `ggml_backend_tensor_copy_async()`；随后 Phone 的 Wdown graph 才执行。 当前 RPC 的 `set_tensor()` 是独立解析 `rpc_tensor + offset + data` 然后 `ggml_backend_tensor_set()`。 而 `GRAPH_RECOMPUTE_SNAPSHOT` 已经能够完成 graph compute + snapshot。

所以不要重写现有 pipeline，**就在这两个边界中间加一个 pending input**。

# 5. 判断 pending input 是不是当前 Wdown graph 的输入

不要只靠顺序。

加：

```cpp
static bool rpc_tensor_depends_on(
        const ggml_tensor * tensor,
        const ggml_tensor * target,
        std::unordered_set<const ggml_tensor *> & visited) {

    if (tensor == nullptr) {
        return false;
    }

    if (tensor == target) {
        return true;
    }

    if (!visited.insert(tensor).second) {
        return false;
    }

    for (int i = 0; i < GGML_MAX_SRC; ++i) {
        if (rpc_tensor_depends_on(
                tensor->src[i],
                target,
                visited)) {
            return true;
        }
    }

    if (rpc_tensor_depends_on(
            tensor->view_src,
            target,
            visited)) {
        return true;
    }

    return false;
}

static bool rpc_graph_uses_tensor(
        const ggml_cgraph * graph,
        const ggml_tensor * tensor) {

    std::unordered_set<const ggml_tensor *> visited;

    for (int i = 0; i < graph->n_nodes; ++i) {
        if (rpc_tensor_depends_on(
                graph->nodes[i],
                tensor,
                visited)) {
            return true;
        }
    }

    return false;
}
```

这样才能确认：

```text
pending ffn_norm
确实是
当前 Wdown graph 的 src
```

```cpp
static bool send_rpc_cmd_compact_dynamic(
        socket_ptr sock,
        enum rpc_cmd cmd,
        const void * input,
        size_t input_size) {

    const size_t packet_size =
        1 + sizeof(uint64_t) + input_size;

    std::vector<uint8_t> packet(packet_size);

    size_t pos = 0;

    packet[pos++] =
        static_cast<uint8_t>(cmd);
```

# 7. Server 把 `set_tensor()` 核心抽出来

```cpp
bool rpc_server::set_tensor_direct(
        const rpc_tensor & in_tensor,
        uint64_t offset,
        const void * data,
        size_t size) {

    struct ggml_init_params params {
        /*.mem_size   =*/ ggml_tensor_overhead(),
        /*.mem_buffer =*/ nullptr,
        /*.no_alloc   =*/ true,
    };

    ggml_context_ptr ctx_ptr {
        ggml_init(params)
    };

    GGML_ASSERT(ctx_ptr != nullptr);

    ggml_tensor * tensor =
        deserialize_tensor(
            ctx_ptr.get(),
            &in_tensor);

    if (tensor == nullptr ||
        tensor->buffer == nullptr) {
        return false;
    }

    const size_t p0 =
        (size_t) ggml_backend_buffer_get_base(
            tensor->buffer);

    const size_t p1 =
        p0 +
        ggml_backend_buffer_get_size(
            tensor->buffer);

    if (in_tensor.data + offset < p0 ||
        in_tensor.data + offset >= p1 ||
        size > p1 - in_tensor.data - offset) {
        return false;
    }

    ggml_backend_tensor_set(
        tensor,
        data,
        offset,
        size);

    return true;
}
```

# 8. Server 新增融合 handler

```cpp
bool rpc_server::set_tensor_recompute_snapshot(
        const std::vector<uint8_t> & input) {

    if (input.size() <
        sizeof(rpc_msg_set_tensor_recompute_snapshot_req)) {
        return false;
    }

    rpc_msg_set_tensor_recompute_snapshot_req request {};

    memcpy(
        &request,
        input.data(),
        sizeof(request));

    const size_t data_size =
        input.size() - sizeof(request);

    if (data_size != request.input_size) {
        return false;
    }

    const void * data =
        input.data() + sizeof(request);

    // 1. ffn_norm 写到 Phone buffer
    if (!set_tensor_direct(
            request.input_tensor,
            request.input_offset,
            data,
            data_size)) {
        return false;
    }

    // 2. Wdown compute + snapshot
    return graph_recompute_snapshot(
        request.graph);
}
```

所以不要再复制 Wdown/snapshot 代码。

## 最重要的 fallback

这一点一定要做。

如果 `SET_TENSOR` 已经被暂存了，但是下一次 graph：

```text

或者
没有 snapshot prepare
或者
当前 graph 不引用这个 ffn_norm
```

否则第一次 `GRAPH_COMPUTE`、异常 graph 或以后改变调度时会使用旧数据。
